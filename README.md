# Swiggy Order Insights Dashboard
Excel dashboard analyzing Swiggy order data across India (Jan-Aug 2025)

## Overview
An Excel dashboard analyzing Swiggy food delivery order data across India, with a region filter to drill down into individual states. Currently viewing: Gujarat, January–August 2025. Built to explore order trends, top restaurants, pricing patterns, and customer ratings.

## Data Source
Swiggy order dataset (India-wide, with state-level filtering, Jan–Aug 2025)

## Tools Used
Excel (Pivot Tables, charts, dashboard design, region filter/slicer)

## Key Metrics (Gujarat view shown)
- **Total Orders:** 10,185
- **Revenue (GMV):** ₹28,17,836
- **Average Order Value:** ₹276.67
- **Average Rating:** 4.39
- **Restaurants Covered:** 60

## Key Insights
- The dashboard supports filtering by state, allowing comparison of order patterns across regions — Gujarat is shown here as an example view.
- Order volume in Gujarat grew steadily from Feb through Jul 2025, peaking in July before a slight dip in August.
- McDonald's, KFC, and Burger King are the top three restaurants by order count, showing strong QSR chain dominance in the region.
- Most orders fall in the ₹100–300 price range, indicating budget-conscious ordering behavior.
- The majority of ratings cluster in the 4.3–4.6 range, reflecting consistently high customer satisfaction.
